# Initial history provenance

The initial implementation was prepared in October 2026. At the repository owner's request, it is organized into substantive incremental commits with retrospective **author dates from July 1 through September 10, 2026**. These dates are a presentation of the initial development sequence, not a claim that the work was performed on those historical days.

Git committer timestamps retain the actual commit-creation dates. The history is merged without squashing so the individual changes and author dates remain available. Later maintenance should use normal contemporaneous dates.

GitHub's contribution graph uses author dates for qualifying commits on the default branch. Account attribution depends on a recognized author email and GitHub's contribution rules; graph updates may be delayed. See [GitHub's contribution troubleshooting](https://docs.github.com/en/account-and-profile/how-tos/contribution-settings/troubleshooting-missing-contributions).
